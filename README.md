# Stanley-sampa
Field Ecologist and Community Professional

Personal portfolio of Stanley Sampa, field ecologist and GIS analyst based in Gwembe District, Zambia: maps, remote sensing analyses, research, upcoming projects, experience and certificates.

- `index.html`: the site
- `img/`: maps rendered from Stanley's own rasters, and scans of professional certificates
- `img/icons/`, `favicon.ico`, `site.webmanifest`: browser, bookmark and home-screen icons, and app shortcuts (Maps, Research, Contact, Download CV)
- `Stanley_Sampa_CV.pdf`: public CV (referee contacts removed; available on request)
- `sitemap.xml`: for submitting the site to Google Search Console

Served with GitHub Pages.
